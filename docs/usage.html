Installation & usage

Quick start for the demo or full ZXP package on Windows and macOS.

System requirements

  • Adobe Illustrator CS6 (17.0) and later
  • CEP runtime 4.0 or later (included with supported Illustrator versions)
  • Windows or macOS

Standalone JSX script (no panel install)

Prefer File → Scripts? Download the free demo as a single file — ILL-EXP-IMP_demo.jsx (same UI as the panel; demo limits: 5 frames / 5 batch files). No other files required.

Full standalone version ($100): after purchase on Adobe Exchange or PayPal, request the unlimited one-file .jsx build by email — same price as the CEP extension.

Install the extension (CEP panel)

  1. Download the .zxp file from GitHub Releases (demo) or from your purchase email (full version).
  2. Install with Anastasiy Extension Manager, ExManCmd, or Adobe Exchange (Plugin ID 205341).
  3. Restart Adobe Illustrator.
  4. Open Window → Extensions → Export-Import text for Illustrator (demo shows … (Demo) in the menu).

Typical translation workflow

  1. Open the Illustrator file and run XML… or XLIFF… export.
  2. Translate the exported file in your CAT tool or editor.
  3. Run the matching import command on the same AI file.
  4. Verify fonts, paragraph alignment, and colors in the layout.

Import requires the same number of paragraphs/lines as in the original export. Empty text frames are removed during export.

Demo limitations

In demo mode the panel footer shows Demo mode. Export/import processes only the first 5 text frames per document and the first 5 files in batch jobs. Reports include a DEMO MODE notice.

Русский — кратко

После установки откройте Окно → Расширения → Export-Import text for Illustrator. Экспортируйте текст в XML или XLIFF, переведите файл, затем импортируйте обратно. Демо обрабатывает только первые 5 фреймов и 5 файлов в пакетном режиме.
